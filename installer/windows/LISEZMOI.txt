AVAStack — Live stacking
========================

Merci d'avoir installé AVAStack !

LANCEMENT
---------
Double-clique sur le raccourci "AVAStack" (Bureau ou Menu Démarrer),
ou sur lancer_avastack.bat dans ce dossier.

SUPPORT DES CAMÉRAS
-------------------
AVAStack gère plusieurs marques de caméras. Les SDK constructeurs sont
INCLUS dans ce dossier d'installation :

✅ INCLUS (aucune action) :
  - QHYCCD  : le SDK est embarqué dans l'installation (paquet qhyccd).
              Branche simplement ta caméra, choisis "QHY (SDK)" dans
              l'application, et c'est parti.
  - ZWO ASI : ASICamera2.dll est installée dans CE dossier (et le paquet
              zwoasi est installé dans le venv).
  - Player One : PlayerOneCamera.dll est installée dans CE dossier.
  - Touptek / Altair : ToupCam.dll est installée dans CE dossier
              (fonctionne aussi pour les clones : Altair et autres
              marques revendant l'électronique ToupCam).
  - SVBONY : SVBCameraSDK.dll est installée dans CE dossier.
  - Simulée : ciel de démo, sans matériel.
  - Dossier surveillé : empile les FITS/PNG/TIFF que ton logiciel
              d'acquisition (N.I.N.A., APT, SharpCap...) écrit dans un dossier.
  - OpenCV : webcams / cartes d'acquisition génériques.

REMARQUE : si tu dois remplacer une DLL par une version plus récente,
copie-la simplement dans CE dossier (ou définis une variable
d'environnement pointant vers le dossier qui la contient, par exemple
AVASTACK_PLAYERONE_DIR=C:\chemin\vers\SDK\PlayerOne).

BANCS DE DIAGNOSTIC CAMÉRA
--------------------------
Trois outils autonomes sont installés avec AVAStack :
  - _diag_camera_qhy.py        (caméras QHY / QHYCCD)
  - _diag_camera_playerone.py  (caméras Player One, ex. Uranus-C Pro)
  - _diag_camera_svbony.py     (caméras SVBONY, ex. SV305C de guidage)

Ils réutilisent le MÊME code caméra que l'application, mais hors
application : idéal pour comprendre un problème de caméra sans toucher au
live stacking.

Pour en lancer un :
  1. ouvre une invite de commandes dans ce dossier ;
  2. tape :  venv\Scripts\python.exe _diag_camera_playerone.py
     (ou      venv\Scripts\python.exe _diag_camera_svbony.py
      ou      venv\Scripts\python.exe _diag_camera_qhy.py)

⚠ UN SEUL programme à la fois peut ouvrir une caméra : fermer le banc
  avant de lancer AVAStack, et inversement.

Le banc PLAYER ONE permet de :
  - DÉTECTER les caméras Player One et lire leur fiche (modèle, capteur,
    couleur/mono, taille, bins supportés, formats, TEC, USB3, ST4) ;
  - OUVRIR la caméra et ÉNUMÉRER AUTOMATIQUEMENT tous ses contrôles
    (attributs min/max/défaut + valeur courante) ;
  - afficher un VERDICT « possibilités » : plages d'exposition, de gain
    (avec le gain unitaire du capteur quand il est connu), d'offset,
    refroidissement TEC, binning, ROI, formats ;
  - RÉGLER en direct : exposition (µs), gain, offset, TEC (consigne +
    arrêt + lecture °C et % de puissance), binning, ROI, format, flip,
    bande passante USB ;
  - AFFICHER le flux live avec les fps réels ;
  - enregistrer un RAPPORT complet dans %TEMP% (bouton « 💾 Sauver le
    rapport »).
  Mode console (détection rapide, sans fenêtre) :
     venv\Scripts\python.exe _diag_camera_playerone.py --console

  ⚠ Le banc réutilise la sonde de l'application : si les fichiers
    avastack\cameras\playerone.py et avastack\cameras\capacites.py
    installés sont ANTÉRIEURS à la version du banc, celui-ci le signale
    (bandeau rouge) au lieu de planter — réinstalle alors la version
    courante d'AVAStack.

Le banc SVBONY permet de (ex. SV305C de guidage) :
  - DÉTECTER les caméras SVBONY (version du SDK, fiche : nom, n° série,
    taille, couleur/mono, bits, Bayer, bins supportés, formats) ;
  - OUVRIR la caméra (SVBOpenCamera — pas d'init séparée dans ce SDK) et
    ÉNUMÉRER AUTOMATIQUEMENT tous ses contrôles via la sonde de
    l'application (SVBGetNumOfControls + SVBGetControlCaps + valeur
    courante) ;
  - afficher un VERDICT « possibilités » : plages exposition / gain /
    BlackLevel (« offset » SVBONY), TEC éventuel, bins, ROI, formats ;
  - RÉGLER en direct : exposition (µs), gain, BlackLevel, TEC (⚠ les
    températures SVBONY sont en unités de 0,1 °C — le banc convertit),
    bin (via SVBSetROIFormat : taille FINALE après bin), format
    (RAW8/RAW16/RGB24…), flip (UN seul contrôle 0-3) ;
  - AFFICHER le flux live avec les fps réels ;
  - enregistrer un RAPPORT complet dans %TEMP%.
  Mode console : venv\Scripts\python.exe _diag_camera_svbony.py --console
  ⚠ Même contrôle de version que le banc Player One : si
    avastack\cameras\svbony.py ou avastack\cameras\capacites.py sont
    antérieurs au banc, celui-ci le signale (bandeau rouge) au lieu de
    planter.

Le banc QHY permet de :
  - DÉTECTER les caméras QHY branchées ;
  - OUVRIR la caméra selon deux séquences (celle de l'application, et une
    pas-à-pas où chaque étape est tracée) ;
  - IMPOSER une ROI (zone de lecture) avant le démarrage du flux ;
  - AFFICHER le flux live, avec les fps et la taille réelle du capteur ;
  - LISTER tous les contrôles du SDK avec leur nom officiel et leur
    valeur (gain, offset, exposition, USB traffic, température...) ;
  - ÉCRIRE n'importe quel contrôle (set_param) ;
  - PILOTER LE REFROIDISSEMENT : consigne de température (régulation
    automatique) ou puissance TEC manuelle, avec lecture de la
    température du capteur et du PWM courant.
    ATTENTION : la MiniCam8M est une caméra REFROIDIE — il lui faut son
    alimentation 12 V pour que la régulation fonctionne (et pour que la
    température lue ait un sens).

En cas de fermeture brutale de la fenêtre sans message (crash natif du
SDK), le bouton "Ouvrir le log" — ou le fichier avastack_qhy_debug.log du
dossier temporaire — indique la DERNIÈRE étape réussie : c'est elle qu'il
faut me transmettre.

TRAITEMENT EXTERNE (optionnel)
-----------------------------
GraXpert et BlurXTerminator (rc-astro.exe) sont détectés automatiquement
s'ils sont installés, sinon indique leur chemin dans l'application
(bouton "…" de la section "Traitement externe"). Ces réglages sont
mémorisés.

FICHIERS DE CONFIGURATION
-------------------------
Tes réglages sont mémorisés dans :
  %APPDATA%\AVAStack\config.json

DÉSINSTALLATION
---------------
Menu Démarrer > AVAStack > Désinstaller AVAStack
(les images et réglages que tu as créés ne sont pas supprimés).
